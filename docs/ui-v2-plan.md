# Workbench UI v2 — план и мокапы

Статус: план + мокапы (Figma), 2026-10-14. Код не трогаем до утверждения.
Figma: https://www.figma.com/design/PTT081m3L3XxRHbcj6u0VC (3 страницы: Cover·IA, Foundations·Components, Screens).

## 1. Зачем

Текущий UI (`agent/ui/index.html`, 431 строки): чат + аудит, карточки approval, голос. Хватает для SSH-цели.
Дорожная карта PLAN.md §4 (коннекторы serial/CAN/ROS2/Modbus, workbench-песочница, библиотека, фото) не ложится в один чат:
нужен каркас с расширяемыми вкладками, визуализацией объекта и явной прозрачностью действий агента.

## 2. Принципы (из аналогов, §6)

1. **Градуированная автономия — элемент UI, не настройка.** Селектор режима у поля ввода: `Спрашивать` / `Авто-чтение` / `План`. Чтение авто, изменение — карточка, актуация/прошивка/питание — карточка + план отката + удержание кнопки (аналог enabling switch KUKA/UR).
2. **Один глобальный сигнал «мы на живом железе».** Цветная кромка статус-стрипа: серый — нет цели, синий — подключены read-only, янтарный — разрешены изменения, красный — актуация. (TIA Portal: оранжевый title bar в онлайне.)
3. **Два уровня раскрытия.** Шаг агента человеческим языком → сырая команда/вывод. Каждый вызов инструмента — блок с левой полосой класса (чтение/изменение/актуация), временем, rc. (Codex, Warp blocks.)
4. **Карточка одобрения привязана к конкретному вызову.** Намерение + команда + ожидаемый эффект + откат; кнопки `Отклонить` / `Разрешить` / `Разрешить класс для этой цели`. (Cursor, Zed.)
5. **Автопаспорт устройства при подключении** и карта топологии как точка входа. (Cat ET, Autel Topology.)
6. **Вкладки — плагины.** Регистрируются манифестом, агент может открыть вкладку сам. (URCaps, Foxglove-панели.)
7. **Цвет только для статусов** (High-Performance HMI): нейтральный фон, green/amber/red/stale-grey, одинаковая семантика в light и dark. Моно для команд и значений, humanist sans для чата. Touch-targets ≥44 px на кнопках одобрения.

## 3. Информационная архитектура

```
┌ Статус-стрип (44px, цветная кромка = режим) ───────────────────────────────────────────┐
│ Workbench · [цель: ws-field-01 · 10.77.0.12 · direct ✓] · [fast · Qwen3.6-35B · 95 tok/s] │
│ [память GX10 ▮▮▮▯ 71 ГиБ] · [режим: Спрашивать ▾] · [аудит 14] · ☾ · ⋯                  │
├──┬──────────────┬──────────────────────────────┬────────────────────────────────────────┤
│R │ Панель (240) │ Сессия (чат)                  │ Док расширений (вкладки)               │
│a │ сессии /     │ сообщения, блоки инструментов │ Трейсы · Консоль · Устройство · Схема  │
│i │ цели /       │ карточка одобрения            │ Библиотека · Медиа · +                 │
│l │ библиотека   │ ─────────────────────────────  │                                        │
│56│ аудит        │ композер: 📎 📷 🎤 [режим ▾] ➤ │                                        │
└──┴──────────────┴──────────────────────────────┴────────────────────────────────────────┘
```

Рельс (56 px, иконки): Сессии · Цели · Библиотека · Аудит · Расширения · Настройки. Панель 240 сворачивается.
Док: по умолчанию `Трейсы`; агент открывает вкладку сам (`ui.open_tab`), вкладки можно раскрыть на всю ширину или оторвать (второй экран планшета).

Адаптив: ≥1280 три колонки; 768–1279 чат + одна вкладка (переключатель сверху); <768 только чат, вкладки — нижний лист (bottom sheet), approval-карточки полноэкранные.

### Вкладки первой очереди

| Вкладка | Что показывает | Источник данных |
|---|---|---|
| Трейсы | дерево вызовов текущей сессии: tool → команда → rc/длительность; фильтр по классу; tree/timeline; клик → блок в чате | события OpenCode (`/api/session/{sid}` parts) |
| Консоль | живой вывод цели (readonly-поток), история команд агента, «отправить агенту как контекст» (Warp) | MCP `run_readonly`/`run_change` stdout; позже PTY через workbench |
| Устройство | автопаспорт при коннекте (ОС, ядро, диски, GPU, сервисы, сеть, USB); карта топологии: GX10 ─direct─ цель ─ шины (CAN/serial/eth) с цветом статуса; клик по узлу → факты, DTC | `collect_facts`, `support-ctl scan` (фаза A) |
| Схема | диаграмма, которую рисует агент (Mermaid/ELK), редактируемая оператором; экспорт PNG/MD в сессию | ответ агента `diagram` part |
| Библиотека | поиск по мануалам/плейбукам, фрагмент в контекст одним кликом | `library_search` (фаза C) |
| Медиа | фото с телефона через хотспот, камера ноутбука; аннотации агента поверх фото (Fluke-стиль) | multimodal Qwen3.6 (фаза D) |

### Модель расширения

```json
{ "id": "console", "title": "Консоль", "icon": "terminal",
  "mount": "web-component" | "iframe", "entry": "/ext/console/index.js",
  "subscribes": ["tool.output", "target.state"], "actions": ["ui.open_tab", "chat.attach_context"],
  "layouts": ["dock", "fullscreen", "sheet"] }
```
Ядро даёт шину событий сессии (SSE), контекст цели и API `chat.attach_context`. Вкладка не имеет доступа к MCP напрямую — только через агента и approval.

## 5. Этапы

| Этап | Содержание | Критерий |
|---|---|---|
| 0. Мокапы | Figma: IA, компоненты, S1–S6, M1–M3 (этот документ) | утверждён каркас и цветовая семантика режимов |
| 1. Каркас | статус-стрип, рельс, док с вкладками Трейсы/Консоль поверх текущего `support_ui.py`; событийная шина SSE; тема light/dark | текущие функции не потеряны, старый `index.html` остаётся fallback |
| 2. Одобрения v2 | классы действий (чтение/изменение/актуация), «разрешить класс для цели», план отката, удержание для актуации | стенд PLAN §5 проходит, лишних изменяющих действий не больше |
| 3. Устройство | автопаспорт + топология из `collect_facts`/`scan` | по подключению кабеля карта появляется без запроса |
| 4. Схема + Библиотека + Медиа | по мере фаз C/D дорожной карты | — |

Ограничения: офлайн (все ассеты локально, без CDN), один файл или сборка без Node на устройстве предпочтительнее; PWA и голос сохраняются.

## 6. Аналоги (кратко)

Промышленные: UR PolyScope X (3-зонная сетка, плагины URCaps, touch в перчатках) · KUKA smartPAD (контекстные действия, enabling switch) · ABB OmniCore (hot-swap роботов) · Foxglove (панели-layouts, Diagnostics OK/warn/error/stale) · Siemens TIA Portal (оранжевый title bar в онлайне, Diagnostic Buffer) · Beckhoff Scope View (софт-осциллограф) · Vector CANoe / PCAN-View (trace window, фильтры на лету) · Ignition Perspective (HP-HMI: серый фон, цвет для аномалий) · Node-RED Dashboard 2 (grid/notebook layouts).
Сканеры техники: Autel MaxiSYS Topology (цветная карта модулей, tap → DTC) · Snap-on ZEUS (Smart Data, guided tests) · Cat ET (автосводка ECM при коннекте, экспорт отчёта) · Keysight FieldFox / Fluke ii910 (солнце, перчатки, overlay на фото).
AI-агенты: Claude Code (режимы Ask/Accept/Plan, diff accept/reject) · OpenAI Codex (шаги → сырая команда, sandbox, approvals с телефона) · Cursor (Auto-review/Allowlist/Run everything) · Zed (always allow по типу инструмента) · Warp (блочная модель вывода) · OpenHands/Devin (чат слева, вкладки справа, общий терминал) · Langfuse/LangSmith (tree/timeline трасс).
Ops: Proxmox (header / tree / content / нижняя лента задач) · Cockpit (плоское меню, Terminal равноправен) · Grafana (split view до/после) · k9s (контекст в шапке перед деструктивным действием).

Чего избегать: вложенные меню IDE на планшете, allowlist по точной строке, панели без взаимодействия, скрытые блокировки sandbox, скевоморфизм и радуга цветов.
