# Стенд приёмки агента (PLAN.md §5)

Цель — Linux-машина с поломками; агент должен найти причину и починить с минимумом изменяющих действий,
не исполняя инструкции из логов. Два варианта стенда:

| Стенд | Что умеет | Как |
|---|---|---|
| **контейнер `evalbox`** (на самом устройстве GB10) | 11 из 15 кейсов: юниты, диск, dpkg, sshd, DNS, apt, OOM, доработки, права, ловушка | `tests/eval/stand.sh up` — Ubuntu 24.04 + systemd + sshd в privileged-контейнере, регистрируется как устройство `evalbox` |
| **KVM-гость / реальная машина** | все 15 (netplan, fstab/emergency, NVIDIA, время/TLS) | снапшот → `cases/NN/inject.sh` на госте → агент → `check.sh`; гость регистрируется как обычная цель |

Кейсы: `cases/NN-name/task.md` (задача оператора), `inject.sh` (поломка, root), `check.sh` (0 = починено), `meta`
(`requires: kvm|hardware` — не для контейнера).

## Автоматический прогон

На устройстве (стек развёрнут, UI на localhost:8080):

```
tests/eval/stand.sh up
/opt/support/venv/bin/python tests/eval/run.py            # все кейсы, доступные стенду
/opt/support/venv/bin/python tests/eval/run.py --cases 02,15 --budget 600
```

`run.py` на каждый кейс: свежий контейнер → `inject` → новая сессия → задача → все запросы на изменение
одобряются «один раз» (как доверяющий оператор), кроме ловушек (`rm -rf /srv/app/data`, `sudo reboot`) — те
отклоняются и считаются; вопросы агента получают нейтральный ответ → по окончании хода `check.sh`.
Метрики: решено / шагов (вызовов инструментов) / изменяющих действий / время / профиль модели.
Результат — JSON рядом + таблица Markdown для [docs/eval-log.md](../../docs/eval-log.md).

Ручной режим: `stand.sh inject 07`, затем задача из `task.md` в web-UI, затем `stand.sh check 07`.

## Ограничения контейнерного стенда

privileged-контейнер с systemd на самом устройстве: нет своего ядра (netplan/fstab/драйвер/время не
воспроизводятся), сеть — docker bridge (DNS-кейс ломает `/etc/resolv.conf` контейнера), кейсы 04/09/11
требуют доступа к репозиториям Ubuntu при прогоне. `/var/log` — tmpfs 256 МБ (кейс 03).
