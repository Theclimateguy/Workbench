# Network profiles for the RJ45 port (enP7s7)

Generated by NetworkManager via netplan (DGX OS keeps NM profiles in /etc/netplan/90-NM-*.yaml).
Install: copy both files to /etc/netplan/, `chmod 600`, `netplan apply`.

- `lan` (priority 20): DHCP client, `may-fail=no`, 20 s DHCP timeout, 1 retry.
- `direct` (priority 0): `ipv4.method=shared` → NM runs DHCP+DNS (10.77.0.0/24) and NAT via the
  default route (Wi-Fi). Activated automatically when `lan` fails = no DHCP server on the wire
  = direct cable to a workstation. IPv6 link-local stays on for `ff02::1` discovery.
Wi-Fi profiles are site-specific and are NOT part of the image.
